# src/types/index.ts

## Purpose

Barrel (re-export) module that gives the rest of the codebase a single import path for all shared type definitions. It aggregates API models, generated AsyncAPI types, and the transport-safe auth-context DTOs so consumers never need to know the individual source files.

## Key elements

- **`export * from '@api/models'`** — re-exports the full set of API model types (DTOs, enums, etc.) under one path.
- **`export * from './asyncapi.generated'`** — re-exports types generated from `asyncapi.yaml` by `npm run gen:asyncapi`. The filename mirrors the spec it is generated from; the paired frontend has its own copy produced the same way.
- **`export type { AuthContext, Caller } from './auth-context'`** — exports the DIP (Dependency Inversion Principle) transport-safe representation of the authenticated user, used wherever a controller or service needs "who is calling."

## Relationships

- All listed neighbors (`src/kernel/authorization.ts`, every `src/modules/account/controllers/*` file, `src/infrastructure/http/request.ts`, `src/infrastructure/adapters/*`, `src/infrastructure/observability/stream.ts`) are **consumers** of the types re-exported here. They import `AuthContext`, `Caller`, API model types, or AsyncAPI-generated types through this single entry point rather than reaching into `@api/models` or the generated file directly.
- `src/infrastructure/adapters/mailer.ts` and `src/infrastructure/adapters/queue.ts` are the most likely consumers of the AsyncAPI-generated message/event types re-exported from `./asyncapi.generated`.

## Notes

- **Generated file is checked in but regenerated by tooling.** `./asyncapi.generated` is written by `npm run gen:asyncapi` from `asyncapi.yaml`. Do not edit it by hand; update the YAML spec and re-run the generator instead.
- **Type-only re-exports.** The `AuthContext`/`Caller` line uses `export type`, so these are erased at compile time. The two `export *` lines are value-and-type re-exports; be aware that importing a name from this file may resolve to either a type or a runtime value depending on the source.
- **Single source of truth for type imports.** If a new shared type is added to `@api/models` or `asyncapi.yaml`, it becomes available to the whole graph automatically through this file—no consumer changes required.
