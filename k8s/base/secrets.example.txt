The keys of the Secret `app-secrets` (one file each under /run/secrets). k8s/rig.sh creates it
with `openssl rand`; a real cluster creates it from its own store. An empty value means unset.

Required, random:
  token_access  token_refresh  totp_encryption_key  pii_encryption_key
  webhook_secret_encryption_key  pseudonym_key  metrics_token  device_cookie_secret  smtp_password

Optional integrations, empty unless used:
  payment_webhook_secret  oauth_google_client_secret  oauth_github_client_secret
  antibot_altcha_secret  antibot_turnstile_secret  posthog_personal_api_key
