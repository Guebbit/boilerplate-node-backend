A monochrome SVG icon used as the Safari pinned-tab icon (the "mask icon"). It is a single black vector silhouette, 558×558 pt, traced from a raster image with potrace.

- `<metadata>`: says the file was generated by potrace 1.14 (Peter Selinger).

- A single `<path>`: contains two subpaths.

## Notes
- It uses one flat color only (`#000000`). Safari pinned tabs treat mask icons as monochrome and recolor them using a `color` attribute on the HTML `<link rel="mask-icon">`. That link is not in this file, so check where the page head or manifest sets it.
- The path data is machine-generated, so it is not meant to be edited by hand. To change the icon, re-trace from the source bitmap.
- The legacy DOCTYPE (SVG 1.0, 2001) is just potrace's default output.
