# tests/unit/scripts/docs/jobs-render.test.ts

## Purpose

Unit tests for the four renderer helpers in `scripts/docs/jobs-render.ts`. Verifies that cron expressions are validated, human-readable, and rendered into both a crontab file and a Markdown ops table in the expected format and order.

## Key elements

- **`job(name, schedule, overrides?)`** – local factory that builds a minimal `JobDeclaration` (only the fields the renderers actually read) for use across all test cases.
- **`describe('looksLikeCron')`** – asserts acceptance of valid 5-field cron strings and rejection of empty, 4-field, 6-field, and free-text inputs.
- **`describe('describeSchedule')`** – checks the human-readable wording for common schedules (`every minute`, `every 5 min`, `02:05 nightly`, fallback to raw back-ticked cron).
- **`describe('renderCrontab')`** – verifies one commented entry per job, declaration-order preservation, the `cd /app && node --import tsx scripts/ops/run-job.ts <name>` command shape, and the "GENERATED by `npm run regenerate`" banner.
- **`describe('renderJobsTable')`** – confirms a leased job (`lease: { ttlMs: 1000 }`) renders a `Yes` in the lease column alongside the worded schedule and summary.

## Relationships

- **`scripts/docs/jobs-render.ts`** – the module under test; all four functions (`looksLikeCron`, `describeSchedule`, `renderCrontab`, `renderJobsTable`) are imported directly from it.
- **`src/kernel/registry.ts`** – provides the `JobDeclaration` type used as the return type of the `job()` helper and as the contract the renderers consume.

## Notes

- Tests use `it.each` for parameterized cases; the `%j` format specifier in one rejection case prints the string with quotes (useful when the input is empty).
- The `renderCrontab` ordering test relies on array index, not alphabetical sort—declaration order is the contract.
- The lease column in the table is exercised only through the `overrides` spread in `job()`, not by constructing a full `JobDeclaration`—keep overrides minimal when adding new test cases.
