# scripts/docs/dependency-groups.ts

## Purpose

The hand-curated half of `docs/tools/package-dependencies.md`. It defines which family each package belongs to, a human-written explanation of why it exists, and a link to deeper docs. The other half of that page—which packages are present and which modules import them—is generated by `generate-dependency-map.ts` and deliberately not duplicated here.

## Key elements

- **`DependencyGroup` (interface)** — Shape for one package family: `name`, `purpose`, `readMore` (Markdown link), and `match` (array of package-name patterns).
- **`RUNTIME_GROUPS` (const)** — Array of `DependencyGroup` covering production packages: HTTP core, security/auth, persistence, cache/messaging, email/rendering/media, observability, i18n, and declared config.
- **`DEV_GROUPS` (const)** — Array of `DependencyGroup` covering build, test, lint, docs, and maintenance tooling that is never shipped.
- **`matchesGroup(packageName, patterns)` (exported function)** — Returns `true` if `packageName` equals one of the patterns or starts with a `prefix*` wildcard (e.g. `@opentelemetry/*` matches `@opentelemetry/sdk-trace-node`).

## Relationships

- **`scripts/docs/generate-dependency-map.ts`** — The generator consumes the group definitions exported here to classify each dependency on the page. Packages that match no group and are imported by more than one module are placed in an "Ungrouped" table rather than causing an error. Packages imported by exactly one module and matching no group are intentionally omitted from this file; the generator lists them under that module's section instead.

## Notes

- Pattern syntax is minimal: a trailing `*` means "prefix match" (`pattern.slice(0, -1)`), everything else is an exact string comparison. There is no full glob support.
- The split between "Ungrouped" (multi-import, unmatched) and "omitted" (single-import, unmatched) is a deliberate design choice: the single-owner case is already visible in the generator's per-module listing, so restating it here would only drift.
- `readMore` values are relative Markdown links (e.g. `[Redis Cache](./redis-cache.md)`); some point to `../theory/` or `../api/` paths outside `docs/tools/`.
