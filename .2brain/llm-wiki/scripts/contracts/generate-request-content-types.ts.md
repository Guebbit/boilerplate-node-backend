# scripts/contracts/generate-request-content-types.ts

## Purpose
Generates a TypeScript export (`REQUEST_CONTENT_TYPES`) mapping each OpenAPI operation that declares a `requestBody` to its accepted media types. The output feeds the 415 content-type guard middleware so that request bodies with undeclared types are rejected rather than silently parsed as empty objects. Backend-only; the frontend has no server to guard.

## Key elements
- **`BODY_METHODS`** — Tuple of the four HTTP verbs that can carry a body (`post`, `put`, `patch`, `delete`); `get`/`head` are excluded by contract.
- **`OperationObject` / `OpenApiDocument`** — Minimal structural type slices for the `openapi.yaml` parse result.
- **`resolveOutputPath()`** — Reads the required `--out <path>` CLI argument and resolves it against the repo root; exits `1` if missing.
- **`checkOnly`** — Boolean set when `--check` is present; switches the script from write mode to compare-and-report mode.
- **`renderRows()`** — Flattens every `METHOD /route` → `[media-type, …]` pair, then sorts the array for a stable diff across regenerations.
- **`output`** — Assembles the full generated file text (header comment, docstring, and the exported `Readonly<Record<string, readonly string[]>>` literal).
- **Final if/else block** — Writes the file, or (in `--check` mode) compares existing content and exits `1` with a remediation message on mismatch.

## Relationships
No graph neighbors are recorded. The file's docblock states its generated output is consumed by `src/infrastructure/http/middlewares/content-type.ts` and is written alongside other files under `api/` that are rebuilt by `npm run gen:api`.

## Notes
- Runs as ESM via the `tsx` shebang; uses `import.meta.url` (not `__dirname`) to derive the repo root.
- `--check` writes nothing and exits `1` on drift — the same contract every generator in this scripts/contracts family keeps.
- Generated output carries a `// Code generated by … DO NOT EDIT.` header and a `/* GENERATED */` block so editors/linters treat it as non-source.
- `toSorted()` (non-mutating) is used for the final sort, preserving the original row order for any downstream use.
- The script reads `openapi.yaml` at the repo root; if that file is absent or malformed the `parse` call will throw before any output is produced.
