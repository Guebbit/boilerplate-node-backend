# scripts/contracts/shared-rules-render.ts

## Purpose

The pure rendering half of the shared-rules code generator. Given a parsed rules document (already schema-checked) and a `GenerateSpec`, it produces the full text of a `.generated.ts` file. It performs no I/O, so unit tests can call it directly without touching the filesystem.

## Key elements

- **`renderGenerated` (exported)** — Top-level entry. Assembles the module header ("GENERATED by `npm run regenerate` … do not edit") plus one `renderExport` block per entry in `spec.exports`, and returns the complete file string (pre-Prettier).
- **`deriveKey` (exported)** — Converts a dot-delimited wire string (`security.api_key.revoked`) into a constant key (`SECURITY_API_KEY_REVOKED`).
- **`renderExport`** (module-private) — Resolves the document slice via `sliceOf`, then renders either a `keyed-list` literal or a pretty-printed `JSON.stringify` wrapped in `as const`, preceded by a docblock and `export const` declaration.
- **`renderKeyed`** (module-private) — Emits an object-literal for `keyed-list` shapes: one docblock + `KEY: "value"` per entry, joined as `{ … } as const`. Throws if two entries derive the same key.
- **`withNumericSeparators`** (module-private) — Post-processes JSON text to insert `_` into integers ≥ 5 digits (e.g. `300000` → `300_000`) to satisfy `unicorn/numeric-separators-style`; string literals are left untouched.
- **`docblock`** / **`sliceOf`** (module-private) — Helpers for comment formatting and safe field extraction from the parsed document (throws if the field is absent).

## Relationships

- **`src/infrastructure/config/shared-rules/generate-spec.ts`** — Source of the `GenerateSpec`, `GeneratedExport`, and `KeyedEntry` types that this module imports and operates on.
- **`scripts/contracts/generate-shared-rule-schemas.ts`** — Sibling in the same generation pipeline; the docstring calls this file the "pure half," implying that script handles the complementary (schema) side.
- **`scripts/scaffold/plan.ts`** — Orchestration layer that plans/invokes the regenerate workflow whose output this module produces.
- **`src/infrastructure/adapters/antibot-providers/altcha.ts`** — Consumer of the *generated* file that this module renders; the altcha adapter imports the constants defined here.
- **`tests/unit/scripts/contracts/shared-rules-render.test.ts`** — Direct unit tests exercising `renderGenerated`, `deriveKey`, and the private helpers.
- **`tests/support/altcha.ts`** / **`tests/unit/infrastructure/adapters/antibot-providers/altcha.test.ts`** — Indirect consumers: they test code that depends on the generated output this module produces.

## Notes

- The module is intentionally **pure** (no `fs`, no `path`); the surrounding script (not shown here) handles file I/O. Tests can therefore call `renderGenerated` with arbitrary in-memory data.
- `withNumericSeparators` runs **after** `JSON.stringify` and only on the raw JSON text; it is a lint-compatibility shim, not a data transformation.
- `renderKeyed` enforces key uniqueness at render time — a validation gap that the schema may not catch.
- The returned string is explicitly "before Prettier"; callers are expected to run a formatter on the result before writing to disk.
