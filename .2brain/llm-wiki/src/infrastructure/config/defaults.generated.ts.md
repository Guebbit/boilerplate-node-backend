# src/infrastructure/config/defaults.generated.ts

## Purpose

A read-only, auto-generated module that centralises the baseline configuration values shared by all backend services. It exists so that a single source of truth (`shared/rules/defaults.yaml`) feeds every service's config without drift.

## Key elements

- **`sharedDefaults`** (`as const` object) — the sole export. Groups default values into five sections:
  - `responseCache` — max dev TTL (30 s) and max cached bytes (256 KiB).
  - `idempotency` — retention window for idempotency keys (24 h).
  - `pagination` — default page size (10).
  - `images` — input limits (50 Mpx, 2048 px max dimension), thumbnail size (320 px), quarantine retention (24 h).
  - `uploads` — max upload size (5 MiB).

## Relationships

- **`src/infrastructure/adapters/config.ts`**, **`src/infrastructure/http/config.ts`**, **`src/infrastructure/persistence/config.ts`** — each service config imports `sharedDefaults` as the starting point and layers environment-variable overrides on top of it.

## Notes

- **Do not edit.** The file is regenerated by `npm run regenerate` from `shared/rules/defaults.yaml`. Change the YAML and re-run the script.
- `as const` makes every leaf a literal type; downstream configs that spread or override these values get narrow types without extra annotation.
- The numeric literals use underscores for readability (`262_144`, `50_000_000`)—keep that style if regenerating from YAML.
