## Purpose

Auto-generated constants file that supplies the default retry-policy values for the outbox. It exists so that a single source of truth (`shared/rules/outbox.yaml`) can be regenerated into TypeScript, eliminating hand-maintained magic numbers in the outbox code.

- **`src/kernel/config.ts`** — Reads environment variables that override the first three fields (`retentionDays`, `maxAttempts`, `leaseSeconds`) before they are applied to the outbox runtime.

- **Do not edit this file by hand.** It is regenerated from `shared/rules/outbox.yaml` via `npm run regenerate`. To change any value, edit the YAML and re-run the generation script.

- Only the first three properties are designed to be environment-overridable; `backoffBaseMs` and `backoffCapMs` are intentionally fixed.
