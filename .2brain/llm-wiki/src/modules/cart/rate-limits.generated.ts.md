- **`cartRateLimitData`** (`as const` object, the sole export) — a keyed map of rate-limit configurations. Each entry carries:
  - `name` — human-readable label.
  - `namespace` — bucket key used by the rate-limiter.

- **Do not edit this file.** It is regenerated from `src/modules/cart/module.yaml`. Change the YAML, then run `npm run regenerate`.
