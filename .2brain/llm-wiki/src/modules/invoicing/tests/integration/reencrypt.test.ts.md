# src/modules/invoicing/tests/integration/reencrypt.test.ts

## Purpose

Integration test that verifies the invoicing module's `reencrypt` walk correctly migrates the buyer's billing address from an old PII encryption key to the newest one, and that a second run is a no-op (idempotent). It also confirms the re-encrypted value still decrypts under the invoice's own ID.

## Key elements

- **Single test case** — *"moves the buyer address to the newest key, and a second run changes nothing"*: creates a user, product, and paid order with a billing address; waits for the resulting invoice; then simulates a key rotation and asserts re-encryption behavior.
- **`withEnvironmentOverrides({ NODE_PII_ENCRYPTION_KEY: rotation })`** — injects a two-version rotation string (`v2:new-pii-key-material,v1:test-pii-encryption-key`) to simulate a key-rotation event without touching real infrastructure.
- **`invoicingModule.reencrypt(false)`** — the operation under test; called twice to assert idempotency (first call rewrites 5 fields, second rewrites 0).
- **`keyVersionOf(raw!.billingAddress!.city)`** — asserts the stored ciphertext is now tagged `v2`.
- **`decryptInvoiceParty(raw!.billingAddress!, 'invoice', raw!._id)`** — asserts the value round-trips to `'London'` when decrypted under the invoice's own ID.
- **`waitForInvoice(orderId)`** — polls until the invoice generated by the paid order is available.

## Notes

- The `rewritten` count of **5** is specific to the test fixture shape (one billing address with five string fields: `fullName`, `street`, `city`, `zip`, `country`). It will break if the model shape changes.
- The second `reencrypt(false)` call asserts idempotency; if the implementation ever adds a new re-encryptable field, the expected `0` may need updating.
- Decryption is verified under the **invoice ID** (per the file's doc comment), not under a bare key version — this is the contract the test locks in.
- The `false` argument to `reencrypt` is passed positionally; its meaning (e.g., dry-run vs. commit) is not documented in this file.
