# src/modules/addresses/controllers/update-address.ts

## Purpose

Provides the two HTTP handlers for `PUT /account/addresses/:addressId` (full replace) and `PATCH /account/addresses/:addressId` (partial merge). Both are thin adapters over a single `addressService.update` call, generated by the shared `createUpdateController` factory so that replace/patch semantics, schema validation, and 404 shaping stay consistent with other entities.

## Key elements

- **`replaceAddress`** – `PUT` handler. Validates the body against `ReplaceAddressBody` (full-document schema), then delegates to the service.
- **`updateAddress`** – `PATCH` handler. Validates the body against `UpdateAddressBody` (partial-merge schema), then delegates to the same service method.
- **`createUpdateController` call** – Configuration object that wires both handlers: sets `entity: 'address'`, `idParam: 'addressId'`, `versioned: false`, `notFoundKey: 'addresses.not-found'`, and a `present` that is a pass-through (the service view is returned as-is).
- **`addressService.update(authContext.id, id, changes)`** – The single service call both handlers funnel into; the auth context id (owner) is passed explicitly for ownership checks.

## Relationships

- **`src/infrastructure/surfaces/create-update-controller.ts`** – Supplies the factory that builds the two handler pairs from the configuration object (schema validation, 404 response, and replace-vs-merge branching).
- **`src/modules/addresses/service.ts`** – Exposes `addressService.update`, which performs the actual write, ownership check, and returns the persisted entry.
- **`src/modules/addresses/routes.ts`** – Imports `replaceAddress` / `updateAddress` and mounts them on the `PUT` and `PATCH` routes respectively.

## Notes

- The route param is `:addressId`, **not** `:id`. The factory defaults to `id`, so `idParam: 'addressId'` is explicitly set here; forgetting this override would silently read an undefined param.
- `versioned: false` means no `ETag` / version header is emitted or checked on these endpoints.
- Ownership is enforced inside the service: a non-owned address returns the same 404 (`addresses.not-found`) as a non-existent one, deliberately avoiding an existence oracle.
- `present` is the identity function; the service view is forwarded unchanged to the response body.
