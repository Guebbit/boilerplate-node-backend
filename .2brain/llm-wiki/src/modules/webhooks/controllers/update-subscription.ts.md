# src/modules/webhooks/controllers/update-subscription.ts

## Purpose

Defines the two HTTP handlers for `PUT /webhooks/subscriptions/:id` (full replace) and `PATCH /webhooks/subscriptions/:id` (partial merge). Both delegate to a single service method and are generated by the shared `createUpdateController` factory. Secret-ring mutations are explicitly excluded and handled by separate action routes.

## Key elements

- **`replaceWebhookSubscription`** — the `PUT` handler. Accepts a full `ReplaceWebhookSubscriptionBody`, calls `webhooksService.updateSubscription`, and returns the resulting subscription.
- **`updateWebhookSubscription`** — the `PATCH` handler. Accepts a partial `UpdateWebhookSubscriptionBody` (merge semantics), same service call.
- **`createUpdateController(...)` invocation** — single factory call that produces both handlers, passing in the entity name, both Zod schemas, the `update` callback, and a `present` serializer.
- **`tenantCallerContextOf(request)`** — extracts the tenant-scoped caller context from the raw request and forwards it to the service.
- **`present` callback** — calls `subscription.toJSON()` to apply the Mongoose `_id → id` rename, then casts to `WebhookSubscription` (the wire type).

## Relationships

- **`create-update-controller.ts`** — supplies the `createUpdateController` factory; this file is one of its consumers, providing the entity-specific config object.
- **`request.ts`** — exports `tenantCallerContextOf`, which this controller calls to derive the tenant context for the service call.
- **`services/index.ts`** — exports `webhooksService`; this controller invokes its `updateSubscription` method as the sole business-logic step.
- **`routes.ts`** — imports and mounts `replaceWebhookSubscription` / `updateWebhookSubscription` onto the corresponding HTTP routes.
- **`types/index.ts`** — provides the `WebhookSubscription` type used to type the serialized response.

## Notes

- The module docstring and the `present` cast are intentional: the Mongoose document is typed as *stored* (with `_id`), while `WebhookSubscription` is the *wire* shape (with `id`). `.toJSON()` performs the rename; the `as` cast bridges the type gap.
- Neither verb manages the secret ring (rotation / removal). Those live in `rotate-subscription-secret.ts` and `remove-subscription-secret.ts` under the same controllers directory.
