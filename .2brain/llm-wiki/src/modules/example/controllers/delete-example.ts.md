# src/modules/example/controllers/delete-example.ts

## Purpose

Implements the single `DELETE /examples/:id` endpoint for the example module. It is hand-written (rather than generated by the shared delete factory) because that factory expects a soft/hard delete triplet, and this module has no soft-delete tier.

## Key elements

- **`deleteExample(request, response)`** — The sole export. Validates the `:id` param, calls `exampleService.removeById` with the caller's context, and responds with `204 No Content` on success or a structured error on failure.

## Relationships

- **`src/infrastructure/http/ids.ts`** — Provides `requireId`, which extracts and validates the path param, writing a 404 and returning `null` when the id is malformed or absent.
- **`src/infrastructure/http/request.ts`** — Provides `callerContextOf`, which derives the authenticated caller's context from the request and passes it to the service.
- **`src/infrastructure/http/response.ts`** — Provides `noContentResponse` (204) for the success path.
- **`src/infrastructure/http/controller.ts`** — Provides `refused` (checks whether the service result signals a rejection and writes the appropriate error) and `catchAs` (maps unexpected thrown errors to a structured 500 response).
- **`src/modules/example/services/index.ts`** — Source of `exampleService`; its `removeById(id, callerContext)` performs the actual persistence deletion and returns a result object the controller interprets.
- **`src/modules/example/routes.ts`** — Registers `deleteExample` as the handler for the `DELETE /examples/:id` route.

## Notes

- **404 conflation by design:** A malformed id, a nonexistent id, *and* an id the caller lacks permission to delete all produce a 404. This is intentional (stated in the JSDoc) and avoids leaking existence information.
- **Early return on invalid id:** When `requireId` fails the function resolves immediately (`Promise.resolve()`) without touching the service — no async work is wasted.
- **No soft-delete flag:** Do not expect a `?hard=true`-style query param here; deletion is always permanent. The shared factory pattern (soft → hard triplet) is deliberately bypassed for this module.
