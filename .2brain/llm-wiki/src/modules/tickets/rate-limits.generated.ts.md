- **Do not edit this file directly.** The header comment and module doc both state it is generated; the source of truth is `module.yaml`.
- `windowMs: 'shared'` is a string token, not a numeric millisecond value — the concrete window is presumably resolved elsewhere (likely in `rate-limits.ts` or a shared config).
